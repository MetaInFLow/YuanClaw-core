# Design Doc Directory Rules

All design documents are stored here.

## Naming
- New design doc: `designdoc-v<version>-<topic>.md`
- Optimization design doc: `optimize-designdoc-v<version>-<topic>.md`

## Minimal required sections
- Background
- Scope
- Architecture / workflow
- Milestones
- Risks and mitigations
- Open questions
