# 功能清单生成器

## 任务目标
本Skill用于将项目方案自动拆解为标准化的功能需求清单和SOW工作内容，提升售前效率和方案一致性。

## 触发条件
当用户表达以下需求时触发：
- "需要把方案拆解成功能清单"
- "项目报价，需要SOW"
- "方案转需求文档"

## 工作流程
```
接收方案 → 评估完整度 → 输出拆解备忘录（中间层）→ 用户确认 → 生成功能清单+SOW
```

## 操作步骤

### 第一步：接收方案并评估完整度
- 输入：用户提供的项目方案（文档或文字描述）
- 处理：智能体分析方案内容
- 判断：
  - 完整：包含业务背景、目标用户、核心功能、技术要求 → 进入第二步
  - 不完整：缺失关键信息 → 提问补齐（"请补充：目标用户是谁？核心功能有哪些？"）→ 进入第二步

### 第二步：输出拆解备忘录
- 处理：按照实施视角拆解方案
- 参考：[references/dismantling-memo-template.md](references/dismantling-memo-template.md)
- 输出：拆解备忘录（中间层，包含：方案要点、隐含需求、模糊地带、功能推导、模块划分、优先级、系统边界）

### 第三步：用户确认和调整
- 请求用户确认拆解备忘录
- 接收用户反馈（"功能模块3不需要"、"增加XX功能"）
- 调整拆解备忘录

### 第四步：生成功能清单和SOW
- 处理：基于确认后的拆解备忘录，生成标准表格
- 参考：
  - [references/feature-list-template.md](references/feature-list-template.md)（功能清单模板）
  - [references/sow-template.md](references/sow-template.md)（SOW模板）
- 输出：功能需求清单 + SOW工作内容（两张表格）

### 第五步：输出质量检查
- 自动检查：
  - [ ] 需求编号格式正确
  - [ ] 功能描述具体可验收
  - [ ] 优先级分配合理
  - [ ] 模块划分清晰
- 输出检查结果，如有问题提示用户调整

## 质量检查清单
- [ ] 方案完整度评估准确
- [ ] 拆解备忘录逻辑清晰
- [ ] 功能描述具体可验收
- [ ] 需求编号格式规范
- [ ] 优先级分配合理
- [ ] 模块划分符合业务逻辑

## 注意事项
- 中间层（拆解备忘录）必须输出，避免一步到位出错
- 信息不足时先提问，不要硬拆
- 功能描述要具体可验收，避免笼统表述
- P0功能不应超过总功能数的30%
- 隐含需求要识别（方案没说但必须做的）

## 边界说明
**能做**：
- 拆解项目方案为功能清单和SOW
- 识别隐含需求和系统边界
- 生成标准化的需求文档

**不能做**：
- 自动设计具体技术方案
- 估算工作量和成本
- 替代用户做业务决策

## 使用示例

### 示例1：电商平台功能清单生成
**用户需求**：需要为电商平台生成功能清单和SOW，用于项目报价

**执行流程**：
1. **接收方案**：用户提供电商平台方案（包含用户管理、商品管理、订单管理等）
2. **评估完整度**：方案完整，进入第二步
3. **输出拆解备忘录**：
   - 方案要点：支持B2C电商，包含商品、订单、支付等核心功能
   - 隐含需求：用户注册需要邮箱验证，订单需要物流跟踪
   - 功能推导：商品管理→商品增删改查、商品上架下架、商品搜索
   - 模块划分：用户管理、商品管理、订单管理、支付管理、物流管理
   - 优先级：用户管理P0，商品管理P0，订单管理P1，支付管理P1，物流管理P2
4. **用户确认**：用户确认拆解正确，补充"需要支持促销活动"
5. **生成功能清单+SOW**：输出两张标准表格
6. **质量检查**：检查通过，完成

**输出**：
- 功能需求清单（15个功能点，包含用户管理、商品管理等）
- SOW工作内容（包含开发、测试、部署等任务）

### 示例2：CRM系统需求拆解
**用户需求**：需要将CRM系统方案拆解为功能清单，用于需求确认

**执行流程**：
1. **接收方案**：用户提供CRM方案（包含客户管理、销售管理、报表等）
2. **评估完整度**：方案缺少技术要求 → 提问："需要支持哪些数据库？需要与其他系统集成吗？"
3. **用户补充**：需要使用MySQL，需要与邮件系统集成
4. **输出拆解备忘录**：...（同上流程）
5. **用户确认**：用户确认
6. **生成功能清单**：输出标准表格
7. **质量检查**：检查通过，完成

**输出**：
- 功能需求清单（20个功能点）
- 技术要求说明（MySQL、邮件集成等）
